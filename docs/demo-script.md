# DMS/SFA MVP Demo Script

This guide walks through the complete MVP demo using mock mode.

## Prerequisites

1. Start in mock mode: `npm run dev`
2. Ensure a Slack app is configured with `/dms` command
3. The mock uses `distributor@demo.com` as the authorised distributor email

## Demo Flow

### 1. Dashboard & Identity

```
User types: /dms
Result: Dashboard with KPIs and Business Insights
- Shows monthly performance metrics
- Shows pending orders, returns, claims
- Shows AI-style business insights
- Identity resolved as "Demo Distributors Ltd"
```

**Expected output**: Welcome dashboard with metrics like "45 total orders", "Rs 2,85,000 total value", and business insights cards.

**Error cases to demo**:
- If email is not mapped: Block with friendly error
- If email is duplicated: Block with admin contact message
- If email scope missing: Informed of users:read.email requirement

### 2. Create Primary Order

```
Click: "Create Primary Order"
Result: Product selection modal showing 5 products from mock catalog
- Beverage Pack A (Rs 125.50/case)
- Snack Box B (Rs 89.00/box)
- Dairy Pack C (Rs 210.00/crate)
- Oil Can D (Rs 350.75/can)
- Spice Mix E (Rs 45.25/packet)
```

```
Click: "Add" on Beverage Pack A (repeat 2x for qty 2)
Click: "Add" on Oil Can D
Result: Selected products shown with quantities
Click: "Review Order"
```

```
Result: Quote review screen
- Shows line item totals
- Shows scheme discount (Multi-Product Discount 5% for 2 items, 10% for 3+ items)
- Shows tax calculation (9%)
- Shows Grand Total
- "Confirm Order" or "Cancel" buttons
Click: "Confirm Order"
```

```
Result: Order confirmation

- Status: Draft
- Line items with pricing

```

**Validation to verify**:
- No products selected → cannot review
- Idempotency prevents double-click create


**Cross-account safety**: Order ID is never from user input — resolved from authenticated context.

### 13. Error Handling Demo (Extended)

**Unauthorized secondary order access**: Cross-account access blocked.
**Blocked features in real mode**:
```
Secondary Order Details → "requires documented REST endpoints (BLK-004)"
ARS Config → "not available via REST API (BLK-008)"
AI Insights → "not available via REST API (BLK-009)"
```
**Duplicate notification prevention**: Idempotency store prevents repeat notifications.

**Unauthorized access**: If another distributor tries to view PO-2026-0001:
```
Result: "You do not have access to this record." (RecordAccessForbiddenError)
```

**Blocked feature**: In real mode, clicking "Review Order" on quote with no pricing endpoint:
```
Result: "Pricing calculation is not available."
```
